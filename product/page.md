# Product

PamAI is an AI-native project-management product whose agent helps users manage projects, conversations, files, schedules, integrations, and related work context.^\[1\]^ (`data:9`) It is positioned as an AI project manager rather than another project-management tool.^\[2\]^ (`data:14`) The product vision is an AI partner that understands the plan, watches the work, and takes the managing off the user’s plate.^\[3\]^ (`data:13`)

## Product surface

PamAI’s working surface combines project and workspace records with conversation, file, and memory context. It stores and retrieves workspaces, projects, messages, files, and memory, and supports user-requested integrations and imports.^\[4\]^ (`data:9`)

The product’s project context includes projects, items, milestones, fronts, batches, and members.^\[5\]^ (`data:9`) Conversations include chat messages, assistant replies, inbox messages, AI-generated summaries, and tool metadata.^\[6\]^ (`data:9`) Uploaded files, project files, user memory, project memory, and file metadata extend that context.^\[7\]^ (`data:9`)

## Workflows and integrations

The product’s AI processing includes prompts, outputs, project context, files, and memory needed to answer user requests.^\[8\]^ (`data:9`) Connected integrations may provide Telegram, WhatsApp, Google Calendar, Notion, ClickUp, and coding-agent client data.^\[9\]^ (`data:9`) For scheduling features, PamAI accesses only the Google user data needed for requested features, including basic profile and email for authentication and calendar events.^\[10\]^ (`data:9`)
